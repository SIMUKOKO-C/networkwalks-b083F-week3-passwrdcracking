# Cybersecurity Practical – Password Cracking & PDF Hash Extraction

## 📌 Overview

This repository documents my hands-on cybersecurity practical work using **WINDOWS** and web-based security tools.

The practical involved working with password-protected files, extracting hashes from PDF files, verifying hash values, and completing a controlled password-cracking challenge.

> **Note:** All activities shown here were performed for learning and cybersecurity training purposes in a controlled environment.

## 🛠️ Tools and Technologies

- KWINDOWS
- Web browser
- Password-cracking challenge environment
- Hash Calculator
- PDF Hash Extractor
- Archive/file manager
- Terminal

## 🎯 Objectives

The practical was completed to gain experience with:

1. Identifying password-protected files.
2. Working with password hashes.
3. Extracting hashes from PDF files.
4. Using hash-calculation and extraction tools.
5. Working with files and archives in WINDOWS.
6. Verifying successful results in a controlled cybersecurity challenge.
